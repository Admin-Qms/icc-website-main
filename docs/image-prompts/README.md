# Image prompts — platform-first positioning

One file per image. Paste the text inside each file's `Prompt` block into Codex as one prompt, one image at a time, and save the result under the file name shown, in `~/Downloads/icc-platform-images/`. The site's image step crops each file to its final size and places it.

Every prompt already includes the house style, so no extra instructions are needed. Reject and regenerate any image with readable text, a logo or brand mark on a device, extra fingers or warped tools.
