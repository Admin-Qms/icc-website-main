# Image prompts — platform-first positioning

One file per image. Paste the text inside each file's `Prompt` block into Codex as one prompt, one image at a time, and save the result under the file name shown, in `~/Downloads/icc-platform-images/`. The site's image step crops each file to its final size and places it.

Every prompt already includes the house style, so no extra instructions are needed. Reject and regenerate any image with readable text, a logo or brand mark on a device, extra fingers or warped tools.

**Where the page images go.** The industry and standard page header images use the `PageHeader` `visual` slot and use these photos. The industries are Manufacturing, Automotive, Aerospace & Defence, Healthcare & Medical Devices, Food & Beverage, Oil Gas & Energy, Construction, and Mining & Natural Resources; there is no Fabrication page. Module page headers (`/solutions/<module>/`) and `/platform/` now carry product loops, not photos.

Placement and the reasoning behind each image: [image brief](../superpowers/specs/2026-10-26-platform-positioning-images.md).
